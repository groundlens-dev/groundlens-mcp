# Put your source document here

This demo runs over a real, current, fact-dense document so hallucinations are easy to catch (invented numbers stand out).

**Recommended:** the **Palantir Q1 2026 Form 10-Q** (the SEC filing — full of hard financial figures). Save it here, e.g. as `pltr-q1-2026-10q.pdf`.

Any PDF works — `rag.py` ingests every `*.pdf` in this folder, so the filename doesn't matter. Drop in your own docs and re-run. PDFs are git-ignored (size + copyright), so nothing here gets committed.
