# Put your source document here

This demo runs over a real, current, fact-dense document so hallucinations are easy to catch (invented numbers stand out).

**Recommended:** the **Palantir – Q1 2026 Business Update** (PDF) from
`investors.palantir.com`. Download it and save it here as `palantir-q1-2026.pdf`.

Any PDF works — drop in your own docs and re-run. PDFs are git-ignored (size + copyright), so nothing here gets committed.
